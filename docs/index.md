# QuickMotion

QuickMotion turns your own character into a working Game Animation Sample (GASP) character in one click: right-click
the mesh, choose **Make GASP Character**, press Play. New here? Start with the [Tutorial](tutorial/before-you-start.md).

!!! tip "New to QuickMotion?"
    Start with the [Tutorial](tutorial/before-you-start.md): your own character moving with the Game Animation Sample in about five minutes.
